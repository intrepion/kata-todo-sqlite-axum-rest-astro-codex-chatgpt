# To Do List

This context defines the language used for a single-person To Do List application built as a learning kata.

## Language

**Task**:
A piece of work the user intends to do, identified by a required title and optionally accompanied by notes.
_Avoid_: Todo, item

**To Do List**:
The user's ordered collection of tasks.
_Avoid_: Project, board

**Active task**:
A task the user has not marked complete and can still work on.
_Avoid_: Open item, pending task

**Completed task**:
A task the user has marked complete and can review later; completion can be reversed.
_Avoid_: Closed task

**Trash**:
A recoverable holding place for tasks removed from the To Do List.
_Avoid_: Archive, deleted task

**Task order**:
The sequence in which active tasks appear, set by the user.
_Avoid_: Sort order
